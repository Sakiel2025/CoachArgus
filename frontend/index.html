使用指南

CoachArgus · 足球智能追踪与运动评估系统 V2.0

1
上传足球视频

在首页上传区拖拽或点击上传视频（支持 MP4、MOV 格式）。视频上传后会自动预览，文件名处可点击重新选择。

2
配置分析选项并开始

视频就绪后，点击开始分析，系统将自动识别球员、分析运动轨迹并生成五维能力画像（防守/射门/传球/速度/体能）。

3
Phase A 完成后：手动标注球员号码必须操作

Phase A（目标检测）完成后，系统会自动弹出球员号码标注弹窗。AI 已自动定位人数最多的关键帧，需要您完成以下操作：

点击画面中的球员检测框，输入对应球衣号码 系统已按颜色自动分组（A 组 / B 组），代表主队与客队 可将裁判、工作人员等非球员标记为非球员以排除干扰 标注完成后点击确认标注，开始 Phase B，系统继续完成深度分析

若跳过标注直接提交，球员将以系统自动编号（如 P1、P2）展示，无法匹配真实号码。

4
查看分析结果

分析完成后右侧面板展示多维结果，包括：

控球率统计（主队 vs 客队） 球员跑动热力图（主队橙色 / 客队蓝色） 动态战术板鸟瞰图（可播放/拖拽进度/筛选队伍） 球员下拉选择器 → 雷达图 + AI深度评估 在线预览 / 下载标注视频
5
个人中心 / 历史记录

点击左侧个人中心，可查看所有历史分析记录，支持按名称搜索、按时间/名称排序。点击查看报告将在当前页面弹出完整分析报告弹窗（含分析概览、控球率、热力图、战术板、球员列表及视频操作），无需切换页面。点击每条记录右侧的 图标可永久删除该记录及其相关文件（视频、热力图等），删除前会弹窗确认。

常见问题
Q: 分析进度卡住？ → 首次运行需加载 YOLO 模型（约 1~3 分钟），CPU 模式下推理较慢，请耐心等待
Q: 视频无法播放？ → 请使用 Chrome 或 Edge 最新版浏览器
Q: 战术板空白？ → 需要视频包含有效的球员追踪数据，球员过少时退回为静态图
